# CS50P-Codes

My practice code and final project from Harvard's [CS50P: Introduction to Programming with Python](https://cs50.harvard.edu/python/). Everything is organized week by week, with comments that explain what each part does.

## Final Project: Personal Expense Tracker
A command-line app that logs expenses by category, saves them to a CSV file, and shows a formatted summary table with the total spent. It includes input validation and `pytest` tests. See the project folder for the full README and a video demo.

## What's inside

| Week | Topic | What I practiced |
|---|---|---|
| 0 | Functions & Variables | input, print, f-strings, defining functions |
| 1 | Conditionals | if / elif / else, match, `%` operator |
| 2 | Loops | for, while, lists, dictionaries |
| 3 | Exceptions | try / except / else, ValueError, input validation |
| 4 | Libraries | random, statistics, sys.argv, APIs, my own library |
| 5 | Unit Tests | assert, pytest, testing functions |
| 6 | File Input-Output | open, CSV files, Pillow |
| 7 | Regular Expressions | re.search, groups, email and URL validation |
| 8 | Object-Oriented Programming | classes, `__init__`, `@property`, inheritance |
| 9 | Et Cetera | `*args`, `**kwargs`, map, list comprehensions, generators |
